Escenario A | Sistemas lineales

Optimización del abastecimiento y red de transporte

Este módulo simula la distribución de productos básicos hacia tres zonas de consumo: Zona Centro - San Pedro, Zona Sur - Obrajes y Zona Norte - Ceja. El sistema se escribe como Ax = b. La matriz A representa relaciones logísticas simplificadas; b es la demanda del producto; x es la distribución calculada.

La simulación permite modificar coeficientes de la matriz, aumentar la demanda por bloqueo y comparar el comportamiento de métodos iterativos y directos.

Métodos obligatorios implementados

JacobiGauss-SeidelSORLUGradiente Conjugado

Datos de contexto: huevo Bs 23-33 antes y Bs 60-65 en crisis; pollo entero Bs 50-55 antes y Bs 100-125 en crisis; papa Bs 40-45 por arroba; aceite bidón amarillo Bs 95 antes y aproximadamente Bs 115 durante la crisis. Estos valores contextualizan el modelo académico.

Explicación de los datos del formulario

Producto

Define el producto que se distribuye. Cada producto tiene una demanda base diferente para San Pedro, Obrajes y Ceja.

Método

Permite elegir Jacobi, Gauss-Seidel, SOR, LU o Gradiente Conjugado. Los primeros, SOR y Gradiente Conjugado son iterativos; LU es directo.

Tolerancia

Es el error mínimo para detener un método iterativo. En LU no se usa porque LU resuelve directamente.

Máx. iteraciones

Es el límite de seguridad para detener el cálculo si el método no alcanza la tolerancia.

Factor ω para SOR

Solo se usa en SOR. Permite relajar o acelerar el avance del método.

Aumento por bloqueo

Representa incremento de demanda por rutas bloqueadas o abastecimiento concentrado.

Interpretación de la matriz y del vector demanda

Matriz A

Cada fila representa una ecuación del sistema y cada columna representa una zona. Las columnas son x1 = San Pedro, x2 = Obrajes y x3 = Ceja. Los coeficientes son editables.

Vector demanda b

El vector b representa la demanda requerida por cada zona. Al resolver Ax=b se obtiene x, que indica cuánto debería enviarse hacia cada zona según el modelo.

Matriz A editable

Se usa una matriz diagonalmente dominante y simétrica para aplicar todos los métodos, incluido Gradiente Conjugado. Puedes modificar cualquier coeficiente antes de calcular.
