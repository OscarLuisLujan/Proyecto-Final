📖 El Escenario

Imagina que circula un audio en redes sociales diciendo: "Se acabó el aceite en los almacenes centrales". Aunque es falso, la gente corre a comprar. La demanda real sube solo un poco, pero el sistema de transporte y distribución (camiones, rutas, almacenes) intenta responder a este pánico. Si la red de distribución es frágil (calles bloqueadas, rutas compartidas), este pequeño empujón matemático provoca un colapso logístico total, creando la escasez real que al principio no existía.

🧠 ¿Cómo funciona esto por detrás?

Para el ciudadano: Usamos una "receta matemática" que intenta equilibrar la oferta y la demanda zona por zona. Si las zonas dependen demasiado unas de otras (mismas rutas), un pequeño cambio en los pedidos hace que la "receta" dé números imposibles (como necesitar 1000 camiones cuando solo hay 10). Eso es el colapso.

Para el evaluador (Método Numérico): Se plantea el sistema $Ax = b$. Se aplica el Método Iterativo de Gauss-Seidel con un criterio de parada de $\epsilon < 10^{-6}$ o máximo 100 iteraciones. Se perturba el vector $b$ con el porcentaje de rumor ($b' = b \cdot (1 + rumor)$). Se calcula el Número de Condición empírico: $K \approx \frac{||\Delta x|| / ||x||}{||\Delta b|| / ||b||}$. Un $K$ alto o la no convergencia del método demuestran que el sistema está mal condicionado.
